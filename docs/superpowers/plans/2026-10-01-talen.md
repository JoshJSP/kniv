# Mesje Talen, stuk 1 — bouwplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Een zevende mesje "Talen" in Kniv: korte leesstukjes in elke taal op jouw niveau, voorgelezen, met tik-op-een-woord.

**Architecture:** Pure logica in `Kniv/Logica/` (Foundation + NaturalLanguage, getest met asserts in `Tests/`), app-diensten (taalmodel op de iPhone, Translation, AVSpeech, Edge Function) in `Kniv/Taal*.swift`, schermen in `Kniv/Talen*.swift`/`Lees*.swift`. Groq alleen via de nieuwe Supabase Edge Function `taal`.

**Tech Stack:** SwiftUI + SwiftData (iOS 18+), FoundationModels (iOS 26, afgeschermd), Translation, AVFoundation, NaturalLanguage, Supabase Edge Functions (Deno), Groq `openai/gpt-oss-120b`.

**Spec:** `docs/superpowers/specs/2026-10-01-talen-design.md`

## Global Constraints
- Deployment target iOS 18.0; Swift 5-taalmodus (project.yml). FoundationModels alleen achter `#if canImport(FoundationModels)` + `#available(iOS 26.0, *)` (zoals `Kniv/Denker.swift`).
- `Kniv/Logica/*.swift` mag alleen `Foundation` en `NaturalLanguage` importeren (wordt los gecompileerd met `swiftc Kniv/Logica/*.swift Tests/*.swift` op macOS).
- Geen nieuwe packages. Geen sleutels in de app. Groq-sleutel (`GROQ_API_KEY`) staat al als Supabase-secret.
- Daglimiet 50 AI-acties per gebruiker per dag, gedeeld met `spraak` via tabel `ai_gebruik`.
- Alle UI-tekst Nederlands als letterlijke `LocalizedStringKey`/`String(localized:)`; Engels komt via `scripts/vertalingen.py` (laatste taak).
- Look: `.glas(radius)` (KnivApp.swift), `KnivAchtergrond()`, `Color.accentColor` (zakmesrood). Geen punten, streaks of spelelementen.
- Niet lokaal te compileren (Windows). Verifiëren = push naar tak `talen` → workflow `check.yml` (logica-checks + app-build). Push naar `main` = release; alleen in de laatste taak.
- Bestaande typenamen niet hergebruiken: `TaalKeuze` (View in Taal.swift) bestaat al.

```swift
// Kniv/Logica/Taalniveau.swift
enum Taalniveau {
    static let codes: [String]                 // ["A1","A1+","A2","A2+","B1","B1+","B2","B2+","C1"], stap = index
    static func code(_ stap: Int) -> String     // begrensd op 0...8
    enum Oordeel { case teMakkelijk, precies, teMoeilijk }
    static func na(_ oordeel: Oordeel, stap: Int) -> Int   // +1 / 0 / -1, begrensd 0...8
    static let startKeuzes: [(code: String, stap: Int)]    // A1 0, A2 2, B1 4, B2 6, C1 8
}

// Kniv/Logica/TaalVermogen.swift
struct TaalVermogen: Equatable {
    var tekstOpToestel: Bool; var vertalenOpToestel: Bool; var stem: Bool
    enum Bron: Equatable { case toestel, online }
    enum WoordBron: Equatable { case woordenlijst, toestel, online }
    var tekstBron: Bron
    func woordBron(inWoordenlijst: Bool) -> WoordBron
    static let niets: TaalVermogen   // alles false
}
enum Talen {
    static func alle(in taal: Locale = .current) -> [(code: String, naam: String)] // 2-letter ISO, zonder "nl", naam met hoofdletter, gesorteerd
    static func naam(_ code: String, in taal: Locale = .current) -> String
    static func zoek(_ tekst: String, in lijst: [(code: String, naam: String)]) -> [(code: String, naam: String)] // exacte code eerst, dan naam bevat
}

// Kniv/Logica/Stukje.swift  (import NaturalLanguage)
struct Stukje: Equatable {
    var titel: String; var tekst: String; var woorden: [String: String] = [:]  // sleutels in kleine letters
    static let maxOnderwerp = 80
    static func schoon(onderwerp: String) -> String        // witruimte → één spatie, trim, max 80
    static func instructies(taalNaam: String, niveau: String) -> String  // voor Denker
    static func prompt(onderwerp: String) -> String
    static func ontleed(_ ruw: String) -> Stukje?          // eerste regel titel (zonder # * " ), rest tekst
    static func ontleedJSON(_ data: Data) -> Stukje?       // {"titel","tekst","woorden"?}, ook binnen ```json … ```
    func isIn(_ code: String) -> Bool                      // false als NLLanguageRecognizer >0.8 zeker nl of en zegt (en dat is niet de doeltaal)
}

// Kniv/Logica/Woorden.swift  (import NaturalLanguage)
struct Woord: Equatable { let tekst: String; let bereik: Range<String.Index> }
enum Woorden {
    static func knip(_ tekst: String, taal code: String) -> [Woord]   // NLTokenizer(.word), zonder numeric/symbolic/emoji
    static func zin(om bereik: Range<String.Index>, in tekst: String) -> String  // NLTokenizer(.sentence), getrimd
    static func lezing(_ woord: String, taal code: String) -> String?  // ja → hiragana, zh → pinyin, anders nil; nil als gelijk aan woord
}

// Kniv/TaalOpslag.swift
@Model final class GekozenTaal { var code = ""; var stap = 0; var volgorde = 0; var toegevoegd = Date()
    init(code: String, stap: Int, volgorde: Int) }
@Model final class Leesstuk { var taal = ""; var titel = ""; var tekst = ""; var onderwerp = ""; var niveau = ""
    var gemaakt = Date(); var woorden: [String: String] = [:]
    init(taal: String, titel: String, tekst: String, onderwerp: String, niveau: String, woorden: [String: String]) }
@Model final class BewaardWoord { var taal = ""; var woord = ""; var betekenis = ""; var zin = ""; var gemaakt = Date()
    init(taal: String, woord: String, betekenis: String, zin: String) }

// Kniv/TaalDiensten.swift
enum TaalDienst {
    enum Fout: Error { case geenInternet, daglimiet, nietIngelogd, mislukt
        var melding: String }   // String(localized:) teksten, zie Task 6
    static func vermogen(_ code: String) async -> TaalVermogen
    static func nieuwStukje(taal code: String, niveau: String, onderwerp: String, vermogen: TaalVermogen) async throws -> Stukje
    static func betekenis(van woord: String, zin: String, taal code: String) async throws -> String
}

// Kniv/Voorlezer.swift
@MainActor @Observable final class Voorlezer: NSObject, AVSpeechSynthesizerDelegate {
    static let shared: Voorlezer
    private(set) var bezig: Bool
    private(set) var gesproken: Range<String.Index>?   // bereik in de laatst gelezen tekst
    nonisolated static func stem(voor code: String) -> AVSpeechSynthesisVoice?  // beste kwaliteit, taal == code of begint met "code-"
    func lees(_ tekst: String, taal code: String, snelheid: Float = 1)  // rate = default * snelheid
    func stop()
}

// Kniv/TalenView.swift
struct TalenView: View      // mesje-scherm, gebruikt in ThuisView
// Kniv/LeesView.swift
struct LeesView: View { init(stuk: Leesstuk) }
struct WoordKaart: View
```
